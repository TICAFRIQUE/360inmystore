Configuration du poste

À faire une seule fois, au premier lancement. Modifiable ensuite via le menu Fichier → Paramètres du poste.

Rôle de ce poste

Ce poste héberge Laragon (Apache/MySQL) et l'application.

Poste serveur
Poste caisse

Utiliser le nom du site (ex. 360_inmystore.test), pas l'IP brute — sinon Apache affiche la liste des dossiers au lieu de l'application. Ce nom doit être ajouté dans le fichier hosts de ce poste, pointant vers l'IP du serveur (voir INSTALLATION-LOCALE.md).
